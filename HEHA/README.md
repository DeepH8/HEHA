# HEHA

game engine course final project



\-3D parkour game-



The game will be inspired by Roblox obby games. It will be a 3D parkour game. It will contain colorful graphics and unique obstacles.



Loop: Run>Jump>Fall/Reach>Checkpoint>Repeat>Win



Controls: WASD, mouse, space, shift



The player starts at last checkpoint if they fall and die, if they reach to the end they win.
